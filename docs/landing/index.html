Una segunda vida segura para lo que nadie se atreve a tocar.

ReVital documenta sistemas viejos y sin papeles, los cruza sin conexión con las vulnerabilidades conocidas y entrega un reporte priorizado por entidad.

02Problema

Funciona, y por eso nadie lo toca.

Drupal 7, Apache sin parchear, Windows 7 en una oficina. Con el tiempo se pierde quién lo montó, qué versión es y qué está expuesto.

01Sin documentación

El inventario vive en la cabeza de alguien que ya no está, o en ningún lado.

02Sin visibilidad

No se sabe qué vulnerabilidades aplican, ni cuáles ya se están explotando en el mundo real.

03Sin presupuesto

Reemplazar todo no es opción hoy. Primero hay que saber qué mitigar, no rehacerlo todo.

04Cómo funciona

Cuatro pasos, todo en tu máquina.

Sin cuentas, sin nube y sin enviar el inventario a nadie.

Paso 1Descubre

Web, código, equipo o red producen un inventario en JSON.

Paso 2Cruza

Compara versiones con NVD y CISA KEV, sin internet.

Paso 3Prioriza

Lo explotado activamente va primero, con acciones concretas.

Paso 4Vigila

La sentinela repite el análisis y avisa de los cambios.

!

Donde faltan datos, ReVital lo dice. «Sin datos» nunca se muestra como «cumple», y lo que depende de parches se marca como «posible», no como «confirmado».

05Por qué ReVital

Hecho para quien no puede mandar su inventario afuera.

Autoalojado
Corre en tu máquina. Sin nube, sin cuentas y sin enviar datos a terceros.
Cero dependencias
Solo biblioteca estándar de Python 3.8+. Corre hasta en Windows 7.
Solo con permiso
Se usa sobre lo tuyo. El reconocimiento de red exige autorización explícita.
Reportes que se leen
Un informe por entidad, en español, para quien decide el presupuesto y no solo para el técnico.
06Empezar

Python 3.8 y el repositorio.

Tres comandos. El repo trae un caso demo, un portal municipal con Drupal 7.57 y Apache 2.4.49 en Docker; los pasos están en COMO-PROBAR.md.

# reporte de vulnerabilidades
python -m revital.cves --out salida

# vigilar un sistema
python -m revital.sentinela --config sentinela.json --una-vez

# panel local
python -m revital.panel --salida salida --puerto 8765 --abrir
