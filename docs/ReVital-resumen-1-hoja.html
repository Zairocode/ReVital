Track 03 Legacy (Build & Pitch 2026) · Descubre qué tecnología corre, cruza NVD + CISA KEV offline y entrega un reporte .md priorizado por entidad

SOLO PYTHON 3.8+ STDLIB · WINDOWS 7+100 % OFFLINE · SIN REESCRIBIR EL LEGACY
Problema: instituciones públicas en Guatemala operan apps web, servidores y software heredado sin documentación ni inventario tecnológico. Cuando salen vulnerabilidades ya explotadas, no saben qué componentes tienen ni qué parchear primero sin romper el servicio.
Usuario concreto: jefe de TI de una municipalidad o entidad pública que heredó sistemas viejos (incluso en Windows 7) y necesita una lista clara y priorizada de qué parchear hoy, sin instalar dependencias ni modificar el sistema.

1Arquitectura: 4 colectores → contrato JSON → evaluación NVD/CISA KEV (offline) → reportes

crawlerWeb / crawler ✔ listo
Headers, cookies, rutas, errores, CMS exacto (Drupal/WP/Joomla), proxy tras backend, PDF/DOCX, robots/sitemap, TLS 1.0 obsoleto. Scope y anti-trampas; --insecure.
directoriosCódigo / carpeta ✔ listo
web.config, pom.xml, composer/npm/NuGet, DLL/JAR, jQuery, versión de Drupal/WP.
hostEquipo Windows local ✔ listo
Registro: Windows, IIS, .NET, IE, programas, parches y puertos. Alerta SMBv1, RDP, sin soporte. .bat de doble clic.
redRed institucional ✔ PoC
Rango de IP: qué servicios hay y qué programa y versión (lee banners). Solo con --autorizo.
salida/inventario-<kind>-<destino>.json { "kind": "web|codigo|host|red", "target": "http://localhost:8080", "entidad": "MUNI-GT", "components": [ {"producto":"Drupal","version":"7.57", "fuente":"archivo /CHANGELOG.txt","donde":"…"}, {"producto":"Apache","version":"2.4.49", "fuente":"error 400 (proxy)","donde":"…"} ], "extra": {} }
Contrato único (inventory.py): cada colector solo llena components. Dos objetivos del mismo tipo ya no se pisan.
1. Componentes
Carga inventario-*.json con cargar_todos()
2. Cruce CVE (NVD)
Alias producto → CPE; versión contra rangos de catalogos/nvd-kev.json
3. ¿Está en CISA KEV?
Sí → prioridad crítica (ransomware, dueDate, acción). Catálogo congelado: 1790 CVE. Agrega parche, mitigación, regla WAF y exploits públicos.
